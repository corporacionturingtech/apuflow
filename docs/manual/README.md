# Manual de APUflow

Guías cortas por rol. Cada usuario ve en el menú solo lo que su rol permite.

| Rol | Qué hace | Guía |
|---|---|---|
| Administrador | Usuarios, empresa, licencia, respaldos | [administrador.md](administrador.md) |
| Precios | Mantiene materiales, equipos, mano de obra, transporte y APUs | [precios.md](precios.md) |
| Cotizador | Arma ofertas y bloques, importa libros de Excel | [cotizador.md](cotizador.md) |
| Lector | Consulta y exporta | [lector.md](lector.md) |

Para quien instala el sistema en una empresa nueva: [checklist-implementacion.md](checklist-implementacion.md).
La instalación técnica en el servidor está en [`deploy/LEEME.md`](../../deploy/LEEME.md).
